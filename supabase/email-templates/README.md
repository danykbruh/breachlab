# Письма BreachLab на русском

Supabase → проект **BreachLab** → **Authentication** → **Emails** (или Email Templates).

| Шаблон в Supabase | Файл | Тема письма (Subject) |
|---|---|---|
| Confirm signup | `confirm-signup.html` | Подтвердите почту - BreachLab |
| Reset password | `reset-password.html` | Сброс пароля - BreachLab |
| Change email address | `change-email.html` | Подтвердите новый адрес - BreachLab |
| Magic link | `magic-link.html` | Вход в BreachLab |

Для каждого шаблона: вставьте тему, откройте файл в Блокноте, скопируйте всё содержимое в поле **Message body** → **Save**.
