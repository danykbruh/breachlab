# BreachLab (рабочее название)

Учебная платформа по кибербезопасности в стиле TryHackMe: комнаты с теорией и заданиями,
проверка ответов на сервере, очки и рейтинг.

## Устройство
- **Сайт** — статический (`index.html`, `css/`, `js/`), хостинг GitHub Pages.
- **Supabase** — аккаунты, база, проверка ответов (`supabase/01_schema.sql`).
- **Ответы** хранятся как `sha256(соль + ответ)` в таблице без доступа для клиента.
  Проверка только через функцию `submit_answer` (лимит 10 попыток в минуту).

## Этапы
- [x] Этап 1: комнаты, задания, аккаунты, рейтинг, профиль
- [ ] Этап 2: учебные машины в Docker на отдельном сервере
- [ ] Этап 3: браузерный терминал
- [ ] Этап 4: индивидуальные флаги, ИИ-подсказки, пути обучения

## Как добавить комнату
1. Скопируйте блок комнаты из `supabase/02_rooms.sql` в новый файл, например `supabase/10_room_<slug>.sql`.
2. Заполните: `slug` (латиница и дефисы), `title`, `summary`, `body_md` (теория в markdown),
   `category` (`soc|web|linux|forensics|crypto|osint`), `difficulty` (`easy|medium|hard`), задания.
3. Файлы для скачивания положите в `rooms/<slug>/` и перечислите в поле `files`:
   `'[{"name":"events.csv","url":"rooms/<slug>/events.csv"}]'`.
4. Запустите файл в Supabase → SQL Editor.
5. Ответы задайте в `supabase/answers.local.sql` (этот файл **не попадает в git**):
   `select public.set_task_answer('<slug>', 1, 'ответ');` — и запустите его в SQL Editor, не сохраняя запрос.

Регистр и лишние пробелы в ответах не важны.

## Правило
Задания учат работать только с учебными материалами платформы. Никаких заданий с реальными
чужими системами или данными.
